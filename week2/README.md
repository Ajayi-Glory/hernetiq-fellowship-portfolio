 Week 2 – Defensive Python & JSON Security Analysis

## Session 3 – Code Review

This week I reviewed a vulnerable Python configuration file for a healthcare AI application. I identified several security issues, including hardcoded credentials, overly permissive IAM policies, and missing secret management. I documented each finding, explained why it matters, assessed its business impact, and recommended practical fixes.

## Session 4 – JSON Log Analysis

This session focused on analysing AWS CloudTrail JSON logs using the IOC 5 Ws framework (Who, What, When, Where, and How). I traced how a stolen API key was used to escalate privileges and gain administrator access to a cloud environment.
